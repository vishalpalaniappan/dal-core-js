# DAL Engine Core JS
This repository contains the core JavaScript implementation of the Design Abstraction Language Engine (DALE).

More details coming soon.

Basic commands:

Build
```
npm run build
```

Start docs server:
```
npm run docs
```

Regenerate docs:
```
npm run docs:api
```
